# Nuestro universo · Leo & Ale

Página romántica estática para GitHub Pages. Incluye `index.html`, dibujos chibi vectoriales (sin fotos reales), carta, contador, sorpresas interactivas y melodía generada en el navegador.

## Publicar desde Android
1. Extrae el ZIP en tu celular.
2. En tu repositorio de GitHub pulsa **Add file → Upload files**.
3. Sube `index.html` y `README.md` a la raíz del repositorio.
4. Pulsa **Commit changes**.
5. Abre **Settings → Pages**. En **Build and deployment**, elige **Deploy from a branch**, branch `main` y carpeta `/(root)`, y guarda.

## Fecha del contador
En `index.html`, busca `const START_DATE=new Date("2026-05-22T00:00:00");` y cambia la fecha provisional por la fecha real en que comenzó la relación. Cambia también el texto de fecha debajo del contador.

La página no usa dependencias ni fotos reales. Si el repositorio es público, la web también será pública; evita añadir datos privados.
